# Customer Cohort Analysis

Tableau project focused on customer cohort analysis and retention patterns in e-commerce.

## Project Overview

This learning project demonstrates how Tableau can be used to analyze customer cohorts, track retention over time, and visualize customer behavior in an interactive dashboard.

## Business Goal

The goal of this project was to analyze customer retention across different cohorts, compare cohort performance over time, and identify patterns in customer behavior.

## Tools & Skills

- Tableau
- Cohort analysis
- Retention analysis
- Customer segmentation
- Data visualization
- Interactive dashboard design
- Business analysis
