# Game Activity Dashboard

Tableau project focused on analyzing user activity, engagement patterns, and game-related performance metrics.

## Project Overview

This learning project demonstrates how Tableau can be used to explore game activity data and present key performance indicators through an interactive dashboard.

## Business Goal

The goal of this project was to analyze user activity, identify engagement patterns, compare performance across different segments, and present the results in a clear interactive dashboard.

## Tools & Skills

- Tableau
- Data visualization
- Interactive dashboard design
- User activity analysis
- KPI analysis
- Filters and segmentation
- Business analysis
